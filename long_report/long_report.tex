\section*{Problem 2. Preparing an image}
\texttt{prepare\_image} converts to RGB, bilinearly resizes the shorter side to 256, takes a central 224-by-224 crop, scales and normalises each colour channel, and returns channels first. The result is \texttt{float32} with shape \texttt{(3, 224, 224)}. It handles transparent PNGs, grayscale images, uppercase extensions, and unreadable files; the split includes each class on both training and test sides.

\subsection*{Loss and generalization}
For the baseline, training loss fell quickly and stayed low, whereas test loss did not improve consistently and rose late in training. The 99.8\% train and 78.3\% test accuracies differ by 21.5 percentage points. This is a generalisation gap, not evidence that the model learned the intended identity cues: the uncleaned set still contained other characters, information screens, and near duplicates.

The most frequent baseline confusion was Lynae versus Yangyang: five Lynae images were classified as Yangyang and three Yangyang images as Lynae. This was surprising given my expectation about hair, although background, additional figures, and search-label contamination are also possible contributors.

My reaction to this result was:
\begin{quote}
``린네와 양양을 혼동한 결과는 놀라웠다. 일단 사용하는 color palette 가 너무 다르기 때문이다. 양양하면 '파란색'이고, 린네하면 '네온 초록'과 '노랑' 계열인데, 어떻게 혼동될까 싶었다.''
\end{quote}

ImageNet initialisation yielded 78.3\% test accuracy versus 51.7\% from random initialisation, a 26.6-point difference. With this small dataset, adapting learned visual features helped. Training only the last layer gave 74.2\%, 4.1 points below full fine-tuning, despite just 2,052 trainable parameters. The early learning-rate variant gave 80.8\%, 2.5 points above the baseline on the same test split.

\subsubsection*{Controlled pixels and the actual model view}
Each source was converted to RGB, bilinearly resized to a 256-pixel short side, then copied as a central 256-pixel square. Passing this canonical copy through \texttt{prepare\_image} produced exactly the same 224-pixel array as preparing the full original. Hair was annotated only after this equivalence check. Thus ``original 256'' below is a display copy that reproduces the original model input, not the full camera frame; ``actual input 224'' shows the central region the model sees.

Before inference, the agent marked visible target-character hair with manually inspected polygons. Eyes, face, hands, clothes, ornaments, and other characters were protected. Masked pixels became RGB(128, 128, 128); all pixels outside the mask were verified unchanged. Original personal photos, training data, earlier crop experiments, and exported model stayed fixed. The reproduction command is:
\begin{verbatim}
uv run --frozen python -B src/hair_mask_experiment.py
  --config config/student_hair_masks.json
\end{verbatim}
The two displayed command lines form one shell command. Fixed coordinates and review notes are in \path{outputs/student_hair_masks_config.json}; the execution code is in \path{outputs/student_hair_masks_code.py}. All class scores and mask-pixel counts are in \path{outputs/student_hair_masks.json} and the complete output below.

Blurred boundaries and tiny printed artwork could not be segmented perfectly. Examples include the car-hood artwork in Lynae \texttt{IMG\_0871}, decorative imagery in Camellya \texttt{IMG\_0583}, and thin hair tips near ornaments. The mask leaves outer hair silhouette, position, and size visible. This is not complete removal of hairstyle; the unfamiliar grey region can itself affect predictions.
